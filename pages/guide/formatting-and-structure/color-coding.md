# Color coding

A text can color its glossing abbreviations. `\color` in the header names an abbreviation, a color and, optionally, a label for the legend.

```gloss
\color ACC #E5323B Acc
\color DAT #B07D00 Dat

\igt
\text mihī causās
  \morph mihī caus-ās
\glmorph 1SG.DAT cause-ACC.PL
```

A morpheme glossed with the abbreviation is colored in the text, and so is the abbreviation in the morphemic gloss (see [Morphemes and morphemic glosses](#guide-morphemes-and-glosses)). A legend above the text shows each color with its label, or the abbreviation if it has none; hover over one to see the abbreviation's full name.

*Color coding*, in the *Marking* group of *Display options*, turns the colors on or off.
